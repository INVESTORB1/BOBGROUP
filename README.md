# BOBGROUP website

Open `index.html` in a browser to preview the website. All editable content is in `index.html`; styling is in `styles.css`.

Before publishing, replace the items marked “placeholder”, update `hello@bobgroup.example`, add real social links, and connect the demo contact form to a form/email service. The phone and WhatsApp links already use 07030803037.

## Deploy on Render

Create a new **Static Site** in Render and connect the GitHub repository. Render will detect `render.yaml`; the publish directory is the repository root and no build command is required.
